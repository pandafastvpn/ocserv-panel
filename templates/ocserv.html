RADIUS 认证说明

本节点通过 RADIUS 进行认证和计费，关键配置：

auth = "radius[config=/etc/radiusclient/radiusclient.conf]"
acct = "radius[config=/etc/radiusclient/radiusclient.conf]"
stats-report-time = {{.Settings.StatsReport}}
select-group = user
config-per-group = /etc/ocserv/config-per-group

RADIUS 负责认证，组策略由本地文件管理（用户组管理）。

select-group = user 允许用户在连接时通过 用户名@组名 选择组，应用对应的限速、路由、DNS 策略。

stats-report-time 控制 ocserv 发送 RADIUS Interim-Update 计费包的频率，包含流量统计信息。
