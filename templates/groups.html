用户组管理

FreeRADIUS 组策略说明

现在使用 FreeRADIUS 认证，ocserv 通过 groupconfig=true 读取 RADIUS 返回的 Class 属性来识别组。

请在 FreeRADIUS 里给用户返回 Class = OU=组名，例如 OU=premium，ocserv 会自动套用此页面里同名组的 DNS / 路由 / 限速策略。

本页面创建的是 ocserv 的本地组配置文件，用于定义该组的限速、路由、DNS、超时等策略。

注意：用户连接时不需要手动输入组名；如果 FreeRADIUS 没有下发 Class，用户将使用默认组。

关于登录界面流程说明

OpenConnect / AnyConnect 协议的标准登录流程是：

① 选择组 + 输入用户名 → ② 点连接 → ③ 输入密码

这是客户端协议层面决定的，ocserv 无法把三个字段强制变成一个页面。若要单页登录，需要定制客户端或 Web Portal。
