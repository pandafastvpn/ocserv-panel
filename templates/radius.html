ocserv 支持的 RADIUS 属性

当 groupconfig=true 时，ocserv 从 RADIUS Access-Accept 回复中读取以下属性：

属性用途
Framed-IP-Address为用户分配指定 VPN IP
Framed-Route向客户端推送路由
Session-Timeout最大会话时长（秒）
Idle-Timeout空闲自动断开（秒）
Acct-Interim-Interval计费更新频率
Class (OU=)分配用户到组
Reply-Message向用户显示消息

Class 属性中的组名用于 RADIUS 下发组策略，不使用本地 config-per-group 文件。
